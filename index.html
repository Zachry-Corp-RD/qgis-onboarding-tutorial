QGIS Onboarding for Google Earth Users

Welcome to QGIS for Google Earth Users

This guide is for Google Earth Pro users who are beginning to use QGIS for mapping, analysis, or GIS projects.

In this quick tour, you'll learn:
- How to match familiar Google Earth workflows in QGIS
- How to import, view, and export KML/KMZ
- Tips to make QGIS feel like home

Familiar Workflows in QGIS

- Add Placemarks Use Point layers in QGIS
- Draw Polygons/Paths Use Polygon and Line layers
- Use KML/KMZ Import via 'Add Vector Layer'
- Toggle visibility Layer Panel checkboxes
- Export views Project > Import/Export > Export to KML

Make QGIS Feel Like Google Earth

- Install QuickMapServices plugin to access Google Satellite
- Enable 'pan/zoom with mouse wheel' in Settings
- Customize toolbars to include: Pan, Identify, Measure, Toggle, Export
- Use bookmarks to replicate saved views

Export to Google Earth from QGIS

To share data back with Google Earth:
1. Right-click a vector layer > Export > Save Features As...
2. Choose 'Keyhole Markup Language (KML)'
3. Customize fields and projection (use EPSG:4326)

Tip: Style layers before export!

Recommended Plugins

- QuickMapServices Google/ESRI/OSM basemaps
- KML Tools Enhanced KMZ/KML support
- Go2StreetView Integrates Google Street View
- Group Stats Summary tables like Earth Engine

Start with a Sample Project

Begin with:

- Sample KML from your GE projects
- Saved bookmarks for key locations

Use QGIS Project files (.qgz) to save your workspace.
